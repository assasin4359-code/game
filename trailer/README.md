# Blade Summoner — 영상

- `blade-summoner-trailer.mp4`: 트레일러 · 1920×1080 · 60fps · 약 51초 (편집 목록 `edl.js`)
- `blade-summoner-duel.mp4`: 단편 「결투」 · 1920×1080 · 60fps · 약 67초 (편집 목록 `duel.edl.js`)
- `blade-summoner-ep1.mp4`: 단편 제1화 「길 좀 묻자」 · 1920×1080 · 60fps · 60초 (편집 목록 `ep1.edl.js`)

영상의 모든 프레임은 게임 자체에서 나옵니다. 헤드리스 Chromium이 디버그 빌드를 실제로 플레이하고, 그 화면을 프레임 단위로 녹화합니다. 효과음도 게임이 호출한 소리를 게임의 WebAudio 신스로 오프라인 렌더링한 것입니다.

음악: **Karl Casey — "Deadly Force"** ([White Bat Audio](https://whitebataudio.com), 로열티 프리). 엔드 카드에 크레딧을 넣었습니다. 사용 조건은 White Bat Audio 사이트의 라이선스를 따릅니다.

| 0:27 | 보스 필살기, 스킬 6종, 천지 가르기 → 사슬의 군주 격파 | 프레이즈 2 (마지막 일격은 31마디 첫 박) |

히든 보스와 일검무귀는 화면에 나오지 않습니다. 마지막 컷의 게임 엔딩 문구로 존재만 암시합니다.

곡은 115 BPM으로 고정돼 있어서(반복 구간 상호상관으로 확인) 모든 컷을 마디 그리드에 놓았습니다. 그리드와 곡 편집 지점은 `edl.js`의 `SONG`에 있습니다.

## 「결투」 — 이름 없는 검사 vs 보우마스터

게임 엔진 위에서 연출한 1:1 결투입니다. 보스 공격은 정해진 프레임에 호출하고, 주인공은 스크립트 입력과 오토파일럿(저스트 회피, 화살 튕겨내기, 점프)으로 움직입니다. 그 위에 레터박스, 카메라, 자막, 임팩트 프레임을 얹었습니다.

| 구간 | 내용 |
| --- | --- |
| 0:00 | 사슬의 묘지. 주인공이 하늘에서 떨어지고, 보우마스터가 나뭇잎 바람과 함께 내려온다 |
| 0:06 | 대치. "넌 누구냐" / "그 사슬, 끊겠다" |
| 0:10 | 록온, 드롭 직전 정적 → 드롭에 광선, 저스트 회피 |
| 0:12 | 1페이즈: 속사, 대지 가르기, 화살 사이클론, 질풍 돌진, 브레이크와 반격 |
| 0:29 | 각성: "깨어나라, 태고의 숲이여" → 숲이 솟는다 |
| 0:37 | 마지막 프레이즈: 유도 화살, 산탄, 보스 필살기 신록의 심판, 가시 범람 |
| 0:51 | 빈틈 → 충전 → 천지 가르기. 마지막 일격이 마디 첫 박에 |
| 0:54 | 정적. 쓰러진다 |
| 0:57 | 세뇌 해제. "내 활의 혼을 가져가라" → 제1장 보우마스터, 해방 |

```sh
EDL=duel.edl.js NAME=blade-summoner-duel CRF=12 PRESET=veryfast FINAL_CRF=25 \
  MUSIC=/path/to/deadly-force.mp3 trailer/make.sh          # → trailer/blade-summoner-duel.mp4
```

카메라는 기본적으로 게임 픽셀 단위로 고정(`snap`)합니다. 배율이 정수로 딱 떨어지게 잡아서 팬이 단순한 화면 이동이 되고, 그래서 영상 용량이 크게 줄어듭니다. 줌이 미끄러지듯 움직이는 다섯 컷만 `snap: false`입니다. `CRF=12`로 거의 무손실 마스터를 뜬 뒤 `FINAL_CRF`로 배포용 크기를 정합니다.

## 단편 제1화 「길 좀 묻자」

게임 로직을 전혀 돌리지 않는 독립 애니메이션입니다. 게임의 캐릭터 리그, 배경, 이펙트, 팔레트와 디더링만 빌려 쓰고, 동작은 컷마다 프레임 단위로 직접 키프레임했습니다(`anim.js`). 기억을 잃은 검사가 사슬의 묘지를 지나가다 보우마스터와 붙는 이야기입니다. 음악은 게임에 내장된 신스 테마(훈련장 → 보우마스터전 → 강화판)만 씁니다.

연출에 쓴 구도: 원경, 걸어오는 검사를 거대한 전경 실루엣 너머로 잡는 컷, 눈 익스트림 클로즈업, 더치 앵글, 화살 추적 숏, 만화식 대각 분할 컷, 집중선 클로즈업, 로우 앵글, 틸트업, 대각선 추적, 지면 높이 숏, 슬로모션 프로필, 록온 클로즈업, 서서히 다가가는 리빌, 교차 베기 와이드, 활 인서트, 투숏.

| 구간 | 내용 |
| --- | --- |
| 0:00 | 잔잔한 음악. 검사가 걸어온다. 전경의 보우마스터, 붉은 눈, 활시위 |

| 0:09 | ? / 분할 컷 "사슬을 거스르는 자는, 모두 꿰뚫는다!" / "...그래서. 여기가 어디냐?" / 분노 |
| 0:16 | 전투 테마. 박자마다 화살을 쳐내며 걸어간다. 화살 계단을 밟고 하늘로, 공중 충돌 |
| 0:23 | 대지 가르기를 슬로모션으로 넘고, 대시 관통, 등 뒤의 화살을 매트릭스식으로 피한 뒤 반격 |

## 다시 만들기

```sh
MUSIC=/path/to/deadly-force.mp3 trailer/make.sh     # → trailer/blade-summoner-trailer.mp4
```

음원 파일은 레포에 넣지 않습니다. `MUSIC`이 없으면 게임 효과음만 들어간 버전이 나옵니다.

필요한 것: node, playwright(Chromium 포함), ffmpeg, python3, curl. 작업 파일은 `trailer/.build/`에 생깁니다.

- `edl.js`, `duel.edl.js`: 편집 목록. 컷 순서, 길이, 카메라, 자막, 음악 큐를 여기서 고칩니다. `make.sh`는 `EDL`로 고르고 `NAME`으로 출력 파일 이름을 정합니다.
- `director.js`: 전투 오토파일럿. 거리 좁히기, 5연타, 위협 감지 시 저스트 회피, 화살 튕겨내기, 대지 가르기 점프, 정해진 프레임에 스킬 사용.
- `anim.js`: 독립 애니메이션용 런타임. 게임 로직 없이 주인공과 보스의 상태·자세를 프레임마다 직접 지정하고, 회전·줌 카메라, 만화식 분할 컷, 집중선과 흐름선, 감정 기호(!, ?, 분노, 땀)를 그립니다.
- `rt.js`: 페이지 안 런타임. 효과음 호출 로그, 카메라(줌·추적·픽셀 고정), 레터박스 자막, 임팩트 프레임, 페이드, 타이틀 카드.
- `capture.js`: 편집 목록을 프레임 단위로 재생해 ffmpeg로 인코딩하고 사운드 로그를 남깁니다.
- `audio.js`: 사운드 로그를 `OfflineAudioContext`로 재생해 효과음 트랙(wav)을 만듭니다.
- `mix.js`: 곡을 편집 목록대로 잘라 붙이고 효과음과 섞은 뒤 라우드니스를 맞춥니다(2패스 선형).

배포용 `index.html`에는 `/*DEBUG*/` 훅이 빠져 있어서, `make.sh`가 `shell.html`과 `[0-9]*.js`로 디버그 빌드를 따로 조립합니다.
