# Blade Summoner — 트레일러

`blade-summoner-trailer.mp4` · 1920×1080 · 60fps · 약 75초

영상의 모든 프레임과 소리는 게임 자체에서 나옵니다. 헤드리스 Chromium이 디버그 빌드를 실제로 플레이하고, 그 화면을 프레임 단위로 녹화합니다. 사운드도 게임이 호출한 효과음과 BGM을 게임의 WebAudio 신스로 오프라인 렌더링한 것입니다. 외부 영상이나 음원 소스는 쓰지 않았습니다.

## 다시 만들기

```sh
trailer/make.sh        # → trailer/blade-summoner-trailer.mp4
```

필요한 것: node, playwright(Chromium 포함), ffmpeg, python3, curl. 작업 파일은 `trailer/.build/`에 생깁니다.

- `edl.js`: 편집 목록. 컷 순서, 길이, 카메라 줌, 자막, 음악 큐를 여기서 고칩니다.
- `director.js`: 전투 오토파일럿. 거리 좁히기, 5연타, 위협 감지 시 저스트 회피, 정해진 프레임에 스킬 사용.
- `rt.js`: 페이지 안 런타임. 효과음 호출 로그, 카메라 크롭, 디더링 페이드, 타이틀 카드.
- `capture.js`: 편집 목록을 프레임 단위로 재생해 ffmpeg로 인코딩하고 사운드 로그를 남깁니다.
- `audio.js`: 사운드 로그를 `OfflineAudioContext`로 재생해 사운드트랙(wav)을 만듭니다.

배포용 `blade-summoner.html`에는 `/*DEBUG*/` 훅이 빠져 있어서, `make.sh`가 `shell.html`과 `[0-9]*.js`로 디버그 빌드를 따로 조립합니다.
